<h1></h1>

Дякуємо за ваш інтерес до **Belay**!

Belay це невелика GitHub Action на TypeScript, яка використовується для
виявлення налаштованих сигналів та, за бажанням, управління запусками робочих
процесів. Ми будемо раді вашим внескам, спрямованим на підвищення надійності,
вдосконалення тестів, документації та зручності використання.

## Перед початком

> [!IMPORTANT]
> Відкрийте issue перед початком роботи над великою функцією або зміною
> поведінки. Невеликі виправлення багів, оновлення документації та точкові
> рефакторинги можна надсилати відразу як pull request.

Якщо ви повідомляєте про проблему або пропонуєте зміну, додайте:

- Що ви очікували побачити
- Що сталося фактично
- Кроки для відтворення проблеми
- Відомості про відповідний Node / pnpm / ОС
- Використана конфігурація

## Вимоги до Pull Request

Робіть pull request-и вузькими за змістом і зручними для рев'ю:

- [ ] Одна логічна зміна на pull request
- [ ] Наявна структура проєкту та правила найменування збережені
- [ ] Документація оновлена при зміні поведінки CLI або публічного SDK
- [ ] Тести додані або оновлені, якщо зміна впливає на поведінку, яку можна
      перевірити автоматично
- [ ] Немає не пов'язаних із задачею змін форматування
