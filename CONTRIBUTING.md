Thank you for your interest in **Belay**!

Belay is a small TypeScript GitHub Action used to detect configured signals and
optionally control workflow runs. Contributions that improve reliability, tests,
documentation, and action ergonomics are welcome.

## Before You Start

> [!IMPORTANT]
> Open an issue before starting work on a large feature or a behavioral change.
> Small bug fixes, documentation updates, and focused refactors can be submitted
> directly as pull requests.

When reporting a problem or proposing a change, include:

- What you expected to happen
- What actually happened
- Steps to reproduce the issue
- Relevant Node / pnpm / OS environment details
- Configuration you used

## Pull Request Guidelines

Keep pull requests focused and easy to review:

- [ ] One logical change per pull request
- [ ] Preserve project structure and naming conventions
- [ ] Update documentation when public behavior or inputs change
- [ ] Add or update tests when the change affects behavior
- [ ] Avoid unrelated formatting-only changes
